Slide 1 • Contexto e Problema

Do Reativo ao Preditivo: Estimando a Vida Útil Restante (RUL)

Previsão do tempo restante em horas até a próxima falha funcional de motores industriais utilizando dados reais da Microsoft Azure.

1. Manutenção Corretiva

Atuação somente após a quebra do equipamento. Eleva o tempo de máquina parada (downtime) e custos de reparo de urgência.

2. Preventiva Fixa

Troca baseada em calendário fixo. Substitui componentes ainda saudáveis e não impede falhas inesperadas entre ciclos.

3. Preditiva Baseada em RUL

Estima em horas a vida útil restante (Remaining Useful Life) e classifica o risco operacional em tempo real via API.

Stack Tecnológica:

Python 3.10+ • FastAPI • Scikit-Learn • MLflow • SQLAlchemy (SQLite) • Pytest • Docker

Base de Dados:

Azure Predictive Maintenance Dataset (5 tabelas integradas)

Slide 2 • Engenharia de Dados

Pipeline Vetorizado sobre as 5 Tabelas Azure PdM

Fusão temporal em janelas de 6h via pd.merge_asof em src/services/ml_service.py, gerando 42.542 registros.

Arquivo (/data) Features / Target Transformação Realizada
PdM_telemetry.csv volt, rotate, pressure, vibration Agregação de média a cada 6 horas para suavizar ruído de alta frequência
PdM_machines.csv age Cruzamento por machineID (idade do equipamento em anos)
PdM_errors.csv recent_errors Soma móvel de erros registrados nas últimas 24 horas
PdM_maint.csv days_since_maint merge_asof (backward) calculando dias decorridos desde a última manutenção
PdM_failures.csv rul_hours (Alvo) merge_asof (forward) calculando horas até a falha seguinte (saturado em 720h)

Slide 5 • API FastAPI e Persistência SQLite

Contratos Pydantic V2 e Auditoria de Predições

Todas as inferências são validadas fisicamente (gt=0, ge=0) e gravadas em predictions.db via SQLAlchemy.

Endpoints REST

  • GET / — Informações gerais da API e link para o Swagger UI (/docs).
  • GET /health — Verifica disponibilidade da API e carregamento do modelo ML.
  • POST /predict — Estima o RUL em horas, classifica risco e grava log no SQLite.
  • GET /predictions — Consulta histórico de predições com filtro por machine_id.

Exemplo de Requisição (POST /predict)

{
  "machine_id": 1,
  "volt": 175.5,
  "rotate": 425.0,
  "pressure": 102.3,
  "vibration": 43.1,
  "age": 12.0,
  "recent_errors": 1,
  "days_since_maint": 10.5
}
